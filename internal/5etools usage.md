# Importing Wildjammer Rules to 5etools.

I maintain an up-to-date custom module for [5etools](https://5e.tools/) so you don't have to constantly copy and paste content from our Wiki.

---

## Installation

### Step 1: Open 5etools
Navigate to [5etools](https://5e.tools/)

### Step 2: Access Homebrew Manager
Go to the top navigation bar → **Utilities** → **Homebrew Manager**
![5etools-1.png](./5etools-1.png)

### Step 3: Load from URL
Click the **"Load from URL"** option

![5etools-2.png](./5etools-2.png)

### Step 4: Enter the Module URL
Paste the following URL:

```
https://raw.githubusercontent.com/leshicodes/wjmais/refs/heads/master/5etools/WJMAiS-modified.json
```

![5etools-3.png](./5etools-3.png)

### Step 5: Confirm
Click **Ok** to load the homebrew content.

---


## Validation
To confirm the module loaded correctly:
1. **Search Homebrew** → Type `Wildjammer`
2. **Verify Author** → Should display `LeshiCodes` under Authors

   ![5etools-4.png](./5etools-4.png)

3. **Browse Content** → Navigate to any rules section (e.g., **Species**)
4. **Check Source Tag** → Look for items with source **"WJMAiS"**

   ![5etools-5.png](./5etools-5.png)

> **Tip:** If you encounter issues, try clearing your browser cache or removing any outdated versions of the homebrew before re-importing.
